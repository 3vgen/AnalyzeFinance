# TestFinance

Python-сервис для анализа личных финансов (мультипользовательский, API + веб).

## Для агентов (обязательно к прочтению)

База знаний проекта — единый источник контекста (продукт, предметная область, технический
стек, архитектура, статус, решения). Перед любой работой ознакомься с ней.

Маршрут чтения:
1. `docs/knowledge-base/40-Проект/Контекст проекта.md` — суть, статус, договорённости.
2. `docs/knowledge-base/40-Проект/Статус проекта.md` и `Roadmap.md` — где мы и куда идём.
3. Хабы в `docs/knowledge-base/00-MOC/` (Архитектура и стек, Области финансов, Методы и метрики, Данные и модель).

Все детали — в wiki-заметках Obsidian; добавлять заметки по правилам из «Контекста проекта».

## Git-договорённости

- Коммиты делать сразу после логического блока, **без запроса пользователя**.
- Сообщения коммитов краткие и по смыслу.
- Ветка `main`, remote `origin`.
