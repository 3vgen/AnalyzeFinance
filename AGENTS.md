# TestFinance

Python-сервис для анализа личных финансов (мультипользовательский, API + веб).

## Для агентов (обязательно к прочтению)

База знаний проекта — единый источник контекста (продукт, предметная область,
технический стек, архитектура, статус, решения). Перед любой работой ознакомься с ней.

Маршрут чтения (подробнее — заметка `Карта знаний.md`):
1. `docs/knowledge-base/Home.md` — точка входа.
2. `docs/knowledge-base/Карта знаний.md` — пошаговый маршрут по уровням.
3. Уровень 1 «Проект»: `10-Проект/Контекст проекта.md` (суть, статус, договорённости),
   `10-Проект/Статус проекта.md` и `10-Проект/Roadmap.md`.
4. Уровни 2–3 (Архитектура, Данные) — по задачам; хабы в начале каждой папки.

Заметки — wiki-заметки Obsidian (ссылки `[[...]]`); добавлять по правилам из «Контекста проекта».

## Git-договорённости

- Коммиты делать сразу после логического блока, **без запроса пользователя**.
- Сообщения коммитов краткие и по смыслу.
- Ветка `main`, remote `origin`.
