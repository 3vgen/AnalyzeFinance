# TestFinance

Python-сервис для анализа личных финансов.

## Для агентов (обязательно к прочтению)

Перед началом работы ознакомься с базой знаний проекта — она хранит весь контекст
(продукт, финансовую модель, методики, состояние проекта и договорённости).

Начни с заметки: `docs/knowledge-base/40-Проект/Контекст проекта.md`
(в ней — состояние, правила БЗ и git-договорённости), затем `Home.md` и хабы в `00-MOC`.

Заметки связаны wiki-ссылками для Obsidian; все добавления должны сохранять эту структуру.

## Git-договорённости

- Коммиты делать сразу после логического блока, **без запроса пользователя**.
- Сообщения коммитов краткие и по смыслу.
- Ветка `main`, remote `origin`.
