# Глоссарий

Краткие определения терминов. Ссылки ведут на подробные заметки.

- [[Доход]] — денежные поступления
- [[Расход]] — денежные траты
- [[Транзакция]] — одна запись о движении денег
- [[Категория]] — классификатор транзакций
- [[Счёт]] — место хранения денег
- [[Активы]] — всё ценное, что есть у человека
- [[Обязательства]] — долги и займы
- [[Чистый капитал]] — активы минус обязательства
- [[Инвестиции]] — размещение денег ради роста
- [[Кэшфлоу]] — денежный поток за период
- [[Бюджет]] — план доходов и расходов
- [[Сберегательная норма]] — доля дохода, уходящая в сбережения
- [[Финансовая подушка]] — резерв на непредвиденное
- [[Финансовые цели]] — измеримые ориентиры
- [[Категоризация]] — отнесение транзакций к категориям
- [[Валюты]] — учёт и пересчёт разных валют
- [[Инфляция]] — обесценивание денег со временем
