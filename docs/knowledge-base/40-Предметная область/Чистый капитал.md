# Чистый капитал

Главный индикатор финансового здоровья:

```
Чистый капитал = Активы − Обязательства
```

## Роль в анализе

- Считается на отчётную дату; [[Валюты|валюты]] пересчитываются в базовую
- Растёт за счёт сбережений (см. [[Сберегательная норма]]), роста [[Инвестиции|инвестиций]] и погашения долгов
- Целевой показатель для [[Финансовые цели|финансовых целей]]
