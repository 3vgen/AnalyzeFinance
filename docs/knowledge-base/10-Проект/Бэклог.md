# Бэклог

Отложенные функции (nice to have). Здесь отмечаем идеи, к которым планируем вернуться, чтобы не потерять контекст. Приоритет и статус появления — в [[Roadmap]] и [[Статус проекта]].

## Автоматический импорт банковских выписок (CSV)

- **Суть**: загрузка выписки из банка файлом и массовое создание транзакций по [[Счёт|счёту]]. См. [[Импорт выписок]].
- **Зачем**: сейчас операции вводятся вручную через API; для реального использования нужен импорт из банка (CSV/Excel), иначе вести финансы неудобно.
- **Статус**: отложено. Модель данных уже готова к этому — уникальный `external_id` по (счёт, источник) обеспечивает дедупликацию при повторной загрузке (ADR-006).
- **Когда вернуться**: после базовой аналитики и интерфейсов, когда ввод данных станет узким местом.

## Автоматическая категоризация транзакций

- **Суть**: автоматически относить транзакции к [[Категория|категориям]] по описанию/контрагенту. См. [[Категоризация]].
- **Зачем**: чтобы не размечать каждую операцию вручную и получать осмысленный [[Анализ расходов]].
- **Статус**: отложено. Полноценное решение предполагает анализ текста операций (правила → вероятностные модели / нейросеть) — это отдельная подсистема и отдельные затраты.
- **Что можно сделать раньше без ML**: простые правила по ключевым словам («содержит X → категория Y») как промежуточный шаг, если понадобится.
