# Продукт

Мультипользовательский веб-сервис для анализа личных финансов: REST API + веб-интерфейс (см. ADR-002, ADR-003). Что это и как устроено.

## Назначение

- Хранить финансовые данные каждого пользователя (см. [[Пользователи и доступ]])
- Автоматически [[Импорт выписок|импортировать]] выписки и [[Категоризация|категоризировать]] транзакции
- Считать метрики: [[Кэшфлоу]], [[Сберегательная норма]], [[Чистый капитал]], [[Финансовая подушка]]
- Строить [[Анализ расходов|анализ расходов]] и контроль [[Бюджет|бюджета]]
- Помогать с [[Финансовые цели|финансовыми целями]]

## Целевой сценарий

- Пользователь регистрируется, добавляет [[Счёт|счета]]
- Импортирует выписки (CSV/банк) или вводит операции
- Получает отчёты и метрики в веб-интерфейсе
- Сервис — многопользовательский: данные изолированы между пользователями
