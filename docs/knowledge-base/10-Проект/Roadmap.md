# Roadmap

План разработки мультипользовательского Python-сервиса анализа личных финансов (API + веб). Пункты отмечаются по мере выполнения; актуальное состояние — в [[Статус проекта]].

## Этап 0 — Фундамент ✅

- [x] База знаний и онбординг (эта заметка и [[Контекст проекта]])
- [x] Архитектурные решения: [[Журнал решений]] (ADR-001…ADR-008)
- [x] Скелет Python-проекта: структура папок (poetry, пакет `testfinance`), зависимости
- [x] ORM-модели ядра: см. [[Модель данных]] и [[Схема базы данных]]
- [x] Alembic и первая миграция (БД `testfinance` на localhost)
- [x] Фундамент приложения: конфиг/`.env`, движок БД, FastAPI + health, seed валют

## Этап 1 — Данные и пользователи ✅

- [x] Seed базовых валют и конфигурация окружения (`.env`, `DATABASE_URL`)
- [x] Регистрация/авторизация [[Пользователи и доступ|пользователей]] (JWT, ADR-007)
- [x] [[Счёт|Счета]] и базовые операции (CRUD с архивацией)
- [x] [[Категория|Категории]] (дерево) и [[Транзакция|транзакции]] (CRUD, фильтры)
