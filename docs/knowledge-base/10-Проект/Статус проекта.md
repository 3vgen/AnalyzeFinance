# Статус проекта

Актуальное состояние проекта: что решено, что делается, что открыто. Это первая заметка для проверки «где мы сейчас». Обновлять при каждом изменении статуса.

## Где мы сейчас

- База знаний проекта создана и структурирована (см. [[Home]]).
- Приняты ключевые архитектурные решения (см. [[Журнал решений]], ADR-001…ADR-006).
- Скелет Python-проекта в `app/` (poetry, SQLAlchemy 2).
- ORM-модели ядра этапа 1 реализованы в `testfinance/models` (см. [[Модель данных]] и [[Схема базы данных]]).
- Alembic настроен; первая миграция применена к БД `testfinance` (PostgreSQL на localhost) — все 6 таблиц созданы.
- Фундамент приложения: конфиг (`testfinance/core/config.py`, `.env`), async-движок/сессия БД, FastAPI с health-эндпоинтами, seed базовых валют (5 шт. добавлены).
- Аутентификация: решено JWT (ADR-007).
- Регистрация/авторизация реализованы: `POST /auth/register`, `POST /auth/login` (JWT), `GET /users/me`; пароли — bcrypt.
- Счета реализованы: CRUD `/accounts` с изоляцией по владельцу и архивацией (мягкое удаление).
- Категории реализованы: дерево `/categories` с защитой от циклов; транзакции `/transactions` (CRUD, знак суммы по kind, фильтры по счёту/категории/датам/kind).
- [[Импорт выписок]] и [[Категоризация|авто-категоризация]] переведены в [[Бэклог]] (nice to have) — вернуться позже.
- Этап 1 «Данные и пользователи» завершён. Следующий шаг: аналитика (см. [[Roadmap]]).

## Принятые решения (кратко)

- Стек: [[Технологический стек]] (ADR-001).
- Продукт: API + веб-интерфейс (ADR-002).
- Модель: мультипользовательская, изоляция по владельцу (ADR-003, см. [[Пользователи и доступ]]).
- Деньги: `Decimal`, исходная валюта без пересчёта (ADR-004).
- Ключи: UUID, для справочников — естественные (ADR-005).
- Ядро модели данных: users/accounts/categories/transactions/currencies (ADR-006).
- Аутентификация: JWT, пароли — bcrypt (ADR-007).
