# Начни здесь

База знаний мультипользовательского Python-сервиса для анализа личных финансов.

Эта заметка — **единственная точка входа**. Открой её первой, дальше следуй по [[Карта знаний|карте знаний]] — там маршрут чтения по уровням.

## Первый шаг

1. **[[Карта знаний]]** — пошаговый маршрут чтения: что читать и в каком порядке.
2. Если хочешь сразу понять суть — начни с [[Контекст проекта]].

## Как устроена база знаний

Заметки разложены по папкам-уровням. Чем меньше число, тем раньше это стоит прочитать:

| Уровень | Папка | Содержание |
| --- | --- | --- |
| 1 | `10-Проект` | суть, статус, план (Контекст, Продукт, Статус, Roadmap, Бэклог) |
| 2 | `20-Архитектура` | стек, архитектура, решения (ADR) |
| 3 | `30-Данные` | модель данных и схема БД |
| 4 | `40-Предметная область` | финансовые концепции (доходы, счета, активы…) |
| 5 | `50-Методы` | методики и метрики анализа |
| 6 | `60-Справочники` | глоссарий (по мере необходимости) |

## Навигация

- [[Карта знаний]] — маршрут чтения для нового агента
- [[Контекст проекта]] — суть, статус, договорённости
- [[Статус проекта]] — где мы сейчас
- [[Roadmap]] — план разработки
- [[Бэклог]] — отложенные функции
