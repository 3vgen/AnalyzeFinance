# Данные и модель

Карта раздела, описывающего источники данных и структуру хранения для сервиса анализа.

## Сущности модели данных

- [[Транзакция]] — атомарная запись о движении денег
- [[Категория]] — классификатор транзакций
- [[Счёт]] — место хранения денег (банк, карта, наличные)
- [[Доход]] и [[Расход]] — две стороны транзакций
- [[Валюты]] — мультивалютный учёт

## Обработка данных

- [[Импорт выписок]] — загрузка данных из банков
- [[Категоризация]] — автоопределение категорий
- [[Модель данных]] — схема БД сервиса
