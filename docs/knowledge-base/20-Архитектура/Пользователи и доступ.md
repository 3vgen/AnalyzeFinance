# Пользователи и доступ

Модель пользователей и изоляции данных в мультипользовательском сервисе.

## Принципы

- Пользователь — владелец своих данных
- Финансовые объекты привязаны к владельцу через `owner_id`
- Запросы всегда ограничены текущим пользователем (фильтрация в репозиториях/сервисах)

## Аутентификация

- JWT-токены или сессии (выбор фиксируется в [[Журнал решений]])
- Пароли — только хеш

## Влияние

- Колонка владельца присутствует во всех финансовых таблицах — см. [[Модель данных]]
- Учитывается на всех уровнях [[Архитектура сервиса|архитектуры]]
