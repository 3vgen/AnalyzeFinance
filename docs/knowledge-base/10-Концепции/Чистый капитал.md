# Чистый капитал

Ключевой индикатор финансового здоровья: все [[Активы]] минус все [[Обязательства]].

```
Чистый капитал = Активы − Обязательства
```

## Зачем считать

- Показывает реальную динамику богатства
- Растёт за счёт сбережений, погашения долгов и роста [[Инвестиции|инвестиций]]
- Именно его изменение отражает качество управления личными финансами

## Роль в анализе

- Целевой показатель для [[Финансовые цели|финансовых целей]]
- Считается на отчётную дату с пересчётом валют (см. [[Валюты]])
