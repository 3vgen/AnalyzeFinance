# Счёт

Место хранения денег: банковский счёт, карта, наличные, электронный кошелёк.

## Типы счетов

- Расчётные и карточные
- Накопительные
- Брокерские (для [[Инвестиции|инвестиций]])
- Наличные
- Кредитные карты и займы (см. [[Обязательства]])

## Роль в анализе

- По счетам проходят все [[Транзакция|транзакции]]
- Счета с положительным остатком — часть [[Активы|активов]]
- Кредитные счета — часть [[Обязательства|обязательств]]

## Учёт валют

Счёт может быть мультивалютным, остатки пересчитываются с учётом [[Валюты|курсов]].
