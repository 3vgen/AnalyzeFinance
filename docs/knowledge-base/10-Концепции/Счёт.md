# Счёт

Место хранения денег: банковский счёт, карта, наличные, кошелёк.

## Типы

- Расчётные и накопительные
- Брокерские — для [[Инвестиции|инвестиций]]
- Кредитные — относятся к [[Обязательства|обязательствам]]

## Роль в модели

- По счетам проходят все [[Транзакция|транзакции]]
- Счета могут быть в разных [[Валюты|валютах]]
- Положительные остатки — часть [[Активы|активов]]
- Данные по счетам приходят из [[Импорт выписок|выписок]]
