# Транзакция

Атомарная запись о движении денег по [[Счёт|счёту]]. Базовая единица всех данных сервиса.

## Поля

- Дата и время
- Сумма: положительная — [[Доход]], отрицательная — [[Расход]]
- [[Категория]] и валюта операции
- Описание и контрагент

## Роль в модели

- Исходные данные для [[Кэшфлоу]], [[Анализ расходов|анализа расходов]] и метрик
- Появляется из [[Импорт выписок|импорта выписок]] или вручную
- Получает категорию через [[Категоризация|категоризацию]]
- Схема хранения — в [[Модель данных]]
