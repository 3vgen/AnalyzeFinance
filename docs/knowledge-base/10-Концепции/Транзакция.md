# Транзакция

Атомарная запись о движении денег по [[Счёт|счёту]]. Базовая единица всех данных сервиса.

## Поля транзакции

- Дата и время
- Сумма (положительная — [[Доход]], отрицательная — [[Расход]])
- [[Категория]] — к чему относится
- [[Счёт]] — по какому счёту прошла
- Валюта (см. [[Валюты]])
- Описание / контрагент / комментарий

## Роль в анализе

- Исходные данные для [[Анализ расходов|анализа расходов]]
- Источник для [[Кэшфлоу]] и всех метрик
- Появляется из [[Импорт выписок|импорта выписок]] или вручную

- [[Категоризация]] — как транзакции получают категории
- [[Модель данных]] — схема хранения
- [[Бюджет]] — сравнение факта с планом
- [[Глоссарий]]
