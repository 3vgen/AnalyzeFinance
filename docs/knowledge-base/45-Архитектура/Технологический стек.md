# Технологический стек

Зафиксированный набор технологий сервиса. Любое изменение — только через [[Журнал решений]].

## Ядро

| Область | Технология | Примечание |
| --- | --- | --- |
| Язык | Python 3.12+ | Типизация через аннотации |
| Web/API | FastAPI | Асинхронный, OpenAPI из коробки |
| Валидация | Pydantic v2 | Модели API и конфигурация |
| БД | PostgreSQL 15+ | Основное хранилище |
| ORM | SQLAlchemy 2.0 | Асинхронный режим |
| Миграции | Alembic | Версионирование схемы |
| Аналитика | Polars | Агрегации по транзакциям (см. [[Методы и метрики]]) |
| Тесты | pytest + httpx | pytest-asyncio для асинхронных тестов |
| Конфигурация | pydantic-settings + `.env` | Секреты не в коде |
| Качество | ruff (линт/формат), mypy (типы) | Проверки перед коммитом |

## Утилиты и среда

- Управление зависимостями — `uv` или `pip` + venv (см. `pyproject.toml`)
- Локальная среда — Docker Compose: `postgres` + приложение
- Логирование — `structlog` (план), стандартный `logging` на старте

## Намерения по слоям

- Слои: API → сценарии (use-cases) → предметные модули → репозитории (SQLAlchemy) → БД. Детали — в [[Архитектура сервиса]].
- Мультипользовательская модель — изоляция по `owner_id`, см. [[Пользователи и доступ]].
- Деньги — `Decimal`, сумма хранится в валюте операции без пересчёта, см. [[Валюты]] и [[Модель данных]].
