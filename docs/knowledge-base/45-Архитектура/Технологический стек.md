# Технологический стек

Зафиксированный набор технологий. Изменения — только через [[Журнал решений]].

| Область | Технология |
| --- | --- |
| Язык | Python 3.12+ |
| Web/API | FastAPI |
| Валидация | Pydantic v2 |
| БД | PostgreSQL 15+ |
| ORM/миграции | SQLAlchemy 2 + Alembic |
| Аналитика | Polars |
| Тесты | pytest |
| Качество | ruff, mypy |

Среда: `pyproject.toml`, Docker Compose для локальной разработки.

- Слои сервиса описаны в [[Архитектура сервиса]]
- Сущности БД — в [[Модель данных]]
- Обоснование решений (ADR) — в [[Журнал решений]]
