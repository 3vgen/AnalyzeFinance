# Пользователи и доступ

Модель пользователей и изоляции данных в мультипользовательском сервисе.

## Пользователь

- Каждая учётная запись — сущность `Пользователь` (логин/email, пароль в хеше, метаданные).
- Все финансовые объекты привязаны к владельцу через `owner_id`.

## Изоляция данных

- Принцип: **пользователь видит только свои данные**.
- Реализация: сквозная фильтрация по `owner_id` в репозиториях/сервисах; проверка доступа при обращении к объекту по id.
- Дальнейшее развитие: передача доступа (общий бюджет, семейный доступ) — как отдельная возможность, не в MVP.

## Аутентификация и авторизация

- Аутентификация: JWT-токены (access + refresh) или сессии — выбор фиксируется в [[Журнал решений]].
- Пароли: только хеш (например, bcrypt/argon2).
- Авторизация: по владельцу объекта и ролям (роль `user`, далее — админ).

## Влияние на данные

- Таблицы финансовых данных содержат колонку владельца. Детали — [[Модель данных]].
- Аналитика и отчёты всегда в контексте текущего пользователя.
