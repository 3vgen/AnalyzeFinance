# Статус проекта

Актуальное состояние проекта: что решено, что делается, что открыто. Это первая заметка для проверки «где мы сейчас». Обновлять при каждом изменении статуса.

## Где мы сейчас

- База знаний проекта создана и структурирована (см. [[Home]]).
- Приняты ключевые архитектурные решения (см. [[Журнал решений]]).
- Приложение ещё не написано — следующий логический этап: проектирование и скелет Python-проекта (см. [[Roadmap]]).

## Принятые решения (кратко)

- Стек: [[Технологический стек]] (ADR-001).
- Продукт: API + веб-интерфейс (ADR-002).
- Модель: мультипользовательская, изоляция по владельцу (ADR-003, см. [[Пользователи и доступ]]).
- Деньги: `Decimal`, исходная валюта без пересчёта (ADR-004).

## Открытые вопросы

- Метод аутентификации: JWT vs. сессии.
- Структура Python-проекта и состав MVP-эндпоинтов.
- Фреймворк веб-интерфейса.
- Состав данных для MVP [[Модель данных|модели данных]] (что реализуем первым).

## Следующие шаги

1. Скелет проекта и среда разработки (Docker Compose, зависимости).
2. Модель данных и первые миграции.
3. Авторизация и управление пользователями.
4. [[Импорт выписок]] и [[Категоризация]] на MVP.
