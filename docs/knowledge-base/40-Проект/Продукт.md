# Продукт

Python-сервис для анализа личных финансов. Что это и как устроено.

## Назначение

- Хранить финансовые данные пользователя
- Автоматически [[Импорт выписок|импортировать]] выписки и [[Категоризация|категоризировать]] транзакции
- Считать метрики: [[Кэшфлоу]], [[Сберегательная норма]], [[Чистый капитал]], [[Финансовая подушка]]
- Строить [[Анализ расходов|анализ расходов]] и контроль [[Бюджет|бюджета]]
- Помогать с [[Финансовые цели|финансовыми целями]]
