# Инфляция

Устойчивый рост цен, из-за которого деньги со временем теряют покупательную способность.

## Почему важна

- Обесценивает наличные и остатки на [[Счёт|счетах]]
- Уменьшает реальную ценность [[Финансовая подушка|подушки безопасности]]
- Делает [[Инвестиции]] необходимыми для сохранения капитала
- Учитывается при постановке [[Финансовые цели|целей]] с горизонтом в годах

## Как учитывать

- Сравнивать доходность [[Инвестиции|инвестиций]] с уровнем инфляции (реальная доходность)
- Планировать цели в ценах будущего периода
- Учитывать [[Валюты|валютную]] составляющую (инфляция разная в разных валютах)
