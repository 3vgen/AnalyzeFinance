# Анализ расходов

Разбор структуры [[Расход|расходов]] для поиска точек оптимизации.

## Что анализируется

- Распределение трат по [[Категория|категориям]]
- Доля постоянных и переменных расходов
- Динамика и сравнение с [[Бюджет|бюджетом]]

## Источники данных

- [[Транзакция|Транзакции]] после [[Категоризация|категоризации]]

## Результат

Понимание, куда уходят деньги, и точки роста [[Сберегательная норма|нормы сбережений]].
