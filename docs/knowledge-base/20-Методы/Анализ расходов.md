# Анализ расходов

Разбор структуры [[Расход|расходов]] для поиска точек оптимизации.

## Что анализируем

- Распределение трат по [[Категория|категориям]]
- Долю постоянных и переменных расходов
- Динамику по месяцам и сезонность
- Сравнение факта с [[Бюджет|бюджетом]]

## Источники данных

- [[Транзакция|Транзакции]], полученные через [[Импорт выписок]]
- [[Категоризация]] для группировки

## Результаты

- Понимание, куда реально уходят деньги
- Выявление «незаметных» трат
- Обоснованные решения для роста [[Сберегательная норма|нормы сбережений]]
