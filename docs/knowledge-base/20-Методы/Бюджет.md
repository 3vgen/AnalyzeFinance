# Бюджет

План движения денег: сколько планируется получить [[Доход|дохода]] и потратить [[Расход|расходов]] за период.

## Виды бюджетов

- Помесячный и годовой
- По категориям (см. [[Категория]])
- По правилам, например [[Правило 50-30-20]]

## Как работает

- Задаются лимиты по категориям расходов
- Фактические траты сравниваются с планом
- Отклонения видны на уровне [[Транзакция|транзакций]]

## Роль в анализе

- Дисциплинирует [[Расход|расходы]]
- Повышает [[Сберегательная норма|сберегательную норму]]
- Помогает достигать [[Финансовые цели|целей]]
