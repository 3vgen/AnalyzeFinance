# Бюджет

План движения денег: сколько планируется получить [[Доход|дохода]] и потратить [[Расход|расходов]] за период.

## Как работает

- Задаются лимиты по [[Категория|категориям]] расходов
- Факт сравнивается с планом на уровне [[Транзакция|транзакций]]
- Отклонения показывает [[Анализ расходов]]

## Роль в анализе

- Контролирует [[Кэшфлоу]]
- Упрощает настройку стартового бюджета с помощью [[Правило 50-30-20]]
- Помогает достигать [[Финансовые цели|целей]] и повышать [[Сберегательная норма|норму сбережений]]
