# Финансовая подушка

Резерв денег на непредвиденные ситуации (потеря дохода, срочные траты, лечение).

## Формула ориентира

Подушка измеряется в месяцах типичных [[Расход|расходов]]:

```
Подушка = сумма резерва / средние расходы в месяц
```

Рекомендуемый диапазон — от 3 до 6 месяцев расходов.

## Зачем нужна

- Защищает от долгов при форс-мажоре (см. [[Обязательства]])
- Позволяет не трогать [[Инвестиции]] в неудачный момент
- Даёт психологическую устойчивость

## Роль в анализе

- Создаётся до начала активных [[Инвестиции|инвестиций]]
- Является частью ликвидных [[Активы|активов]]
- Отдельная [[Финансовые цели|финансовая цель]] для контроля

## Фактор

- [[Инфляция]] постепенно обесценивает резерв — важно следить
