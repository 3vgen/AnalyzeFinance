# Сберегательная норма

Доля [[Доход|дохода]], которую удаётся отложить.

```
Сберегательная норма = (Доход − Расход) / Доход × 100%
```

## Почему важна

- Главный драйвер роста [[Чистый капитал|чистого капитала]]
- Норма 20%+ считается здоровой

## Как повышать

- Контроль [[Расход|расходов]] через [[Бюджет]]
- Оптимизация структуры трат в [[Анализ расходов|анализе расходов]]
- Ориентир распределения — [[Правило 50-30-20]]
