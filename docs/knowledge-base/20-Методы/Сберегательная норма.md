# Сберегательная норма

Доля [[Доход|дохода]], которую удаётся отложить, а не потратить.

## Формула

```
Сберегательная норма = (Доход − Расход) / Доход × 100%
```

## Почему важна

- Главный драйвер роста [[Чистый капитал|чистого капитала]]
- Показывает, сколько денег идёт на [[Финансовые цели|цели]] и будущее
- Норма 20%+ считается здоровой для большинства ситуаций

## Как повышать

- Контроль [[Расход|расходов]] через [[Бюджет]]
- Оптимизация структуры трат (см. [[Анализ расходов]])
- Рост дохода

- [[Финансовая подушка]]
