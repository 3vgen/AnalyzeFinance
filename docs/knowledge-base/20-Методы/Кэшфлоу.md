# Кэшфлоу

Денежный поток: движение денег за период. Разница между [[Доход|доходами]] и [[Расход|расходами]].

```
Кэшфлоу за период = Доходы − Расходы
```

## Виды

- **Положительный** — доходы превышают расходы, есть что сберегать
- **Отрицательный** — тратим больше, чем зарабатываем (рост долгов)

## Роль в анализе

- Основа [[Бюджет|бюджета]] и прогнозов
- Определяет [[Сберегательная норма|норму сбережений]]
- Напрямую влияет на способность обслуживать [[Обязательства|обязательства]]

## Учёт

Считается на основе [[Транзакция|транзакций]] по [[Счёт|счетам]] с учётом [[Валюты|валют]].
