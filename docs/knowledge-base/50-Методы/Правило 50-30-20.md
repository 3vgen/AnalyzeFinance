# Правило 50-30-20

Простой способ распределения чистого [[Доход|дохода]]:

- **50% — нужды** (обязательные [[Расход|расходы]])
- **30% — желания** (развлечения, хобби)
- **20% — сбережения** (см. [[Сберегательная норма]])

## Как применять

- Нужды и желания разделяются через [[Категория|категории]]
- Правило — ориентир для старта [[Бюджет|бюджета]], а не жёсткий закон
- Сверка структуры трат — в [[Анализ расходов|анализе расходов]]
