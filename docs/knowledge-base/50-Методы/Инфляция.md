# Инфляция

Устойчивый рост цен, из-за которого деньги теряют покупательную способность.

## Почему важна

- Обесценивает [[Финансовая подушка|резервы]] и остатки на счетах
- Делает [[Инвестиции]] необходимыми для сохранения капитала
- Учитывается при постановке [[Финансовые цели|целей]] с длинным горизонтом
- По-разному проявляется в разных [[Валюты|валютах]]
