# Кэшфлоу

Денежный поток: разница между [[Доход|доходами]] и [[Расход|расходами]] за период.

```
Кэшфлоу = Доходы − Расходы
```

## Виды

- Положительный — есть что сберегать
- Отрицательный — тратим больше, чем зарабатываем

## Роль в анализе

- Основа [[Бюджет|бюджета]] и прогнозов
- Определяет [[Сберегательная норма|норму сбережений]]
- Отрицательный поток подрывает [[Финансовая подушка|подушку]] и накапливает долги

## Учёт

Считается из [[Транзакция|транзакций]] по счетам.
