# Финансовая подушка

Резерв на непредвиденные ситуации. Измеряется в месяцах типичных [[Расход|расходов]], обычно 3–6.

## Зачем нужна

- Защищает от долгов при форс-мажоре
- Позволяет не трогать [[Инвестиции]] в неудачный момент
- Часть ликвидных [[Активы|активов]]

## Роль в анализе

- Создаётся до активных инвестиций
- Наполняется из сбережений (см. [[Сберегательная норма]])
- Обесценивается под действием [[Инфляция|инфляции]] — за резервом нужно следить
