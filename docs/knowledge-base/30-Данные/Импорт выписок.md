# Импорт выписок

Загрузка финансовых данных из внешних источников (банки, CSV, OFX).

## Процесс

1. Загрузка выписки по [[Счёт|счёту]]
2. Разбор в черновые [[Транзакция|транзакции]]
3. [[Категоризация]] и дедупликация
4. Запись в базу (см. [[Модель данных]])

## Сложности

- Разные форматы и разделители
- Разные [[Валюты]] и форматы чисел
- Повторные и ошибочные записи — нужна дедупликация
