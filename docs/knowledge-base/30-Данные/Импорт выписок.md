# Импорт выписок

Загрузка финансовых данных из внешних источников (банки, карты, CSV/OFX/API).

## Источники

- Выписки по [[Счёт|счетам]] в CSV и Excel
- Форматы OFX/QIF, банковские API
- Ручной ввод как запасной вариант

## Процесс

1. Загрузка файла выписки
2. Разбор строк в черновые [[Транзакция|транзакции]]
3. [[Категоризация]] и сопоставление со счётом
4. Дедупликация (защита от повторного импорта)
5. Запись в базу (см. [[Модель данных]])

## Сложности

- Разные форматы и разделители
- Разные [[Валюты]] и форматы чисел
- Повторяющиеся и ошибочные записи
