# Модель данных

Схема хранения данных Python-сервиса. Отвечает на вопрос «как данные лягут в базу».

## Ключевые сущности

- [[Транзакция]] — движения денег (ядро модели)
- [[Счёт]] — носитель денег
- [[Категория]] — дерево классификаторов
- [[Валюты]] — коды валют и курсы
- Периоды и отчётные даты

## Связи

- Счёт → много транзакций
- Категория → много транзакций (через [[Категоризация]])
- Транзакция имеет валюту и сумму в валюте счёта

## Принципы

- Хранить исходную сумму в валюте [[Транзакция|транзакции]] без пересчёта
- Курсы хранить исторически, чтобы пересчёты были воспроизводимы
- Не удалять данные, только помечать (аудит)
