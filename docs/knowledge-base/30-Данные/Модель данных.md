# Модель данных

Схема хранения данных Python-сервиса. Отвечает на вопрос «как данные лягут в базу». Сервис мультипользовательский, БД — PostgreSQL, доступ через SQLAlchemy 2 + Alembic (см. [[Технологический стек]] и ADR-001 в [[Журнал решений]]).

## Ключевые сущности

- [[Пользователи и доступ|Пользователь]] — владелец данных
- [[Транзакция]] — движения денег (ядро модели)
- [[Счёт]] — носитель денег
- [[Категория]] — дерево классификаторов
- [[Валюты]] — коды валют и курсы
- Периоды и отчётные даты

## Связи

- Пользователь → его счета, категории, транзакции (через `owner_id`)
- Счёт → много транзакций
- Категория → много транзакций (через [[Категоризация]])
- Транзакция имеет валюту и сумму в валюте счёта

## Принципы

- Хранить исходную сумму в валюте [[Транзакция|транзакции]] без пересчёта (см. ADR-004)
- Курсы хранить исторически, чтобы пересчёты были воспроизводимы
- Не удалять данные, только помечать (аудит)
- Изоляция: все финансовые таблицы содержат владельца; запросы ограничены им (см. [[Пользователи и доступ]])
