# Валюты

Валюта операций и счетов. **На MVP сервис работает только с рублями** (ADR-008): механика хранения «сумма + код валюты» остаётся в модели, но пересчёт между валютами не реализуется.

## Текущие правила (MVP)

- Код валюты по ISO 4217 (`RUB` и др. в каталоге `currencies`).
- Счета и операции на MVP заводятся в рублях.
- [[Транзакция|Транзакции]] хранятся в исходной валюте без пересчёта (ADR-004).
- Аналитика считается по каждой валюте отдельно без конвертации.

## Отложено (не в MVP)

- Пересчёт в базовую валюту для отчётов.
- Исторические курсы `exchange_rates` и конвертация при аналитике.

Схема хранения — в [[Модель данных]].
