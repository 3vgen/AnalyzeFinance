# Валюты

Учёт денег в разных валютах и пересчёт между ними.

## Принципы

- Коды валют по ISO 4217
- [[Транзакция|Транзакции]] хранятся в исходной валюте без пересчёта
- Курсы — исторические, на дату операции
- Схема хранения — в [[Модель данных]]

## Где применяется

- Остатки [[Счёт|счетов]]
- Пересчёт в базовую валюту для отчётов
- Учитывается в расчёте [[Чистый капитал|чистого капитала]]
