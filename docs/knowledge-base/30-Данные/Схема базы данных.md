# Схема базы данных

Полное описание таблиц и колонок ядра модели (этап 1). Реализация — ORM-модели в `app/testfinance/models/`, источник истины — код; здесь — справочное описание. Соглашения по типам и ключам — в [[Модель данных]].

## users — пользователи

| Колонка | Тип | Примечание |
| --- | --- | --- |
| id | UUID | PK (ADR-005) |
| email | VARCHAR(320) | unique, index |
| password_hash | VARCHAR(255) | только хеш пароля |
| display_name | VARCHAR(100) | nullable |
| is_active | BOOLEAN | default true |
| created_at / updated_at | TIMESTAMPTZ | UTC |

См. [[Пользователи и доступ]].

## currencies — каталог валют

| Колонка | Тип | Примечание |
| --- | --- | --- |
| code | VARCHAR(3) | PK (ISO 4217), естественный ключ |
| name | VARCHAR(100) | |
| symbol | VARCHAR(10) | nullable |
| exponent | SMALLINT | число знаков после запятой, default 2 |

См. [[Валюты]].

## exchange_rates — исторические курсы

| Колонка | Тип | Примечание |
| --- | --- | --- |
| base_code | VARCHAR(3) | PK, FK → currencies.code |
| quote_code | VARCHAR(3) | PK, FK → currencies.code |
| rate_date | DATE | PK |
| rate | NUMERIC(18,8) | сколько quote стоит 1 base; CHECK > 0 |

PK = (base_code, quote_code, rate_date). Хранение курсов на дату даёт воспроизводимый пересчёт (ADR-004).

## accounts — счета

| Колонка | Тип | Примечание |
| --- | --- | --- |
| id | UUID | PK |
| owner_id | UUID | FK → users.id (CASCADE), index |
| name | VARCHAR(150) | |
| type | VARCHAR(20) | `checking/savings/cash/credit/brokerage/other` |
| currency_code | VARCHAR(3) | FK → currencies.code |
| opening_balance | NUMERIC(19,4) | открытый остаток, default 0 |
| is_archived | BOOLEAN | default false |
| created_at / updated_at | TIMESTAMPTZ | |

Актуальный баланс считается по транзакциям; `opening_balance` нужен для выверки старта. См. [[Счёт]].

## categories — дерево категорий

| Колонка | Тип | Примечание |
| --- | --- | --- |
| id | UUID | PK |
| owner_id | UUID | FK → users.id (CASCADE), index |
| parent_id | UUID | само-ссылка → categories.id (CASCADE), index, nullable для корневых |
| name | VARCHAR(150) | |
| kind | VARCHAR(20) | `income` / `expense` |
| is_archived | BOOLEAN | default false |
| created_at / updated_at | TIMESTAMPTZ | |

Дерево строится через `parent_id` (adjacency list). См. [[Категория]] и [[Категоризация]].

## transactions — движения денег

| Колонка | Тип | Примечание |
| --- | --- | --- |
| id | UUID | PK |
| owner_id | UUID | FK → users.id (CASCADE), index |
| account_id | UUID | FK → accounts.id (CASCADE), index |
| category_id | UUID | FK → categories.id (SET NULL), index, nullable |
| currency_code | VARCHAR(3) | FK → currencies.code — валюта операции |
| amount | NUMERIC(19,4) | знак: + доход, − расход (ADR-004) |
| occurred_on | DATE | дата операции из выписки |
| description | VARCHAR(500) | nullable |
| external_id | VARCHAR(100) | nullable; внешний ключ источника |
| is_archived | BOOLEAN | default false |
| created_at / updated_at | TIMESTAMPTZ | время записи в БД |

Уникальный индекс `(account_id, external_id) WHERE external_id IS NOT NULL` — дедупликация импорта (см. [[Импорт выписок]]). См. [[Транзакция]].
