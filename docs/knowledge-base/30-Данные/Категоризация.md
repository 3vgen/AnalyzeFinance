# Категоризация

Процесс отнесения [[Транзакция|транзакций]] к [[Категория|категориям]].

## Способы

- По правилам: контрагент/описание → категория
- По ключевым словам в описании транзакции
- Постоянные правила, обучающиеся на ручных исправлениях
- Ручное назначение как финальный контроль

## Роль в анализе

- Без корректной категоризации невозможны [[Анализ расходов]] и [[Бюджет]]
- Качество категоризации определяет доверие к отчётам

## Качество

- Мера: доля транзакций без категории
- Периодическая проверка нераспознанных записей
