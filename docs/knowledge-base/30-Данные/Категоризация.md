# Категоризация

Отнесение [[Транзакция|транзакций]] к [[Категория|категориям]].

## Способы

- По правилам: контрагент/ключевые слова → категория
- Правила обучаются на ручных исправлениях
- Ручное назначение как контроль

## Роль

- Без категорий невозможны [[Анализ расходов]] и [[Бюджет]]
- Выполняется при [[Импорт выписок|импорте]] и после него
